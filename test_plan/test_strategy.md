# Test Strategy – WorkflowPro

## Objective
To validate login, multi-tenant isolation, project management workflows, and cross-platform compatibility of the WorkflowPro B2B SaaS platform.

## Scope
- Web UI automation using Playwright
- API automation using pytest + requests
- Integration testing (API + UI + Mobile)
- Multi-tenant security validation

## Test Types
- Smoke Tests
- Regression Tests
- Integration Tests
- Cross-Browser Tests
- Tenant Isolation Tests

## Out of Scope
- Performance testing
- Load testing
- Penetration testing
